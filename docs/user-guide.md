## 快速入门

1. 打开 FormatForge 首页，你会看到所有可用工具的卡片列表。
2. 点击任意工具卡片进入对应的转换器页面。
3. 在输入区域输入内容，大多数工具会**实时自动转换**，无需点击按钮。
4. 在输出区域查看结果，可以一键**复制**或**下载**。

> **隐私提示**：所有数据均在你的浏览器本地处理，不会上传到任何服务器。关闭页面后数据即消失。

## 主题切换

FormatForge 支持三种主题模式：

| 模式 | 说明 |
|------|------|
| 浅色 | 始终使用亮色背景 |

| 系统 | 自动跟随操作系统的主题设置 |

**切换方法**：点击页面右上角的太阳/月亮/显示器图标，从下拉菜单中选择你喜欢的主题。

## 通用操作

以下操作在所有工具中通用：

### 输入内容

- **手动输入**：在输入文本框中直接键入内容
- **文件上传**：点击输入区域下方的文件上传按钮，或直接将文件拖拽到输入区域
- **粘贴**：使用 `Ctrl+V`（macOS 为 `Cmd+V`）粘贴内容

### 获取结果

- **复制**：点击输出区域的「复制」按钮，将结果复制到剪贴板
- **下载**：点击输出区域的「下载」按钮，将结果保存为文件

### 转换统计

大多数工具底部会显示转换统计信息：

- **处理时间**：转换所花费的时间
- **输入大小**：输入数据的字节大小
- **输出大小**：输出数据的字节大小

## 工具详解

### 1. JSON ↔ CSV 转换器

在 JSON 数组和 CSV 格式之间互相转换，适合数据导入导出场景。

#### 操作步骤

1. 选择转换方向：「JSON → CSV」或「CSV → JSON」
2. 在输入区域粘贴 JSON 数组或 CSV 数据
3. 转换结果实时显示在输出区域

#### 配置选项

| 选项 | 说明 | 默认值 |
|------|------|--------|
| 分隔符 | 选择逗号、制表符、分号或自定义分隔符 | 逗号 (,) |
| 包含表头 | CSV 输出是否包含列名行 | 是 |
| 展开嵌套对象 | 将 JSON 中的嵌套对象展开为扁平列（仅 JSON → CSV 模式） | 是 |

#### 示例

**JSON 输入**：

```json
[
  {"name": "张三", "age": 25, "city": "北京"},
  {"name": "李四", "age": 30, "city": "上海"}
]
```

**CSV 输出**：

```csv
name,age,city
张三,25,北京
李四,30,上海
```

### 2. Base64 编解码

将文本或文件编码为 Base64 格式，或将 Base64 字符串解码还原。

#### 操作步骤

**编码模式**：

1. 选择「编码 (Encode)」模式
2. 在输入区域输入文本，或点击「上传文件编码」按钮选择文件
3. 编码结果实时显示

**解码模式**：

1. 选择「解码 (Decode)」模式
2. 在输入区域粘贴 Base64 字符串
3. 解码结果实时显示
4. 如果输入的是 Data URL（如 `data:image/png;base64,...`），会自动检测并提供「下载解码文件」按钮

#### 配置选项

| 选项 | 说明 |
|------|------|
| 上传文件编码 | 仅编码模式可用，将文件内容编码为 Base64 Data URL |
| 下载解码文件 | 仅解码模式且检测到 Data URL 时可用 |

#### 示例

**编码**：输入 `Hello, FormatForge!` → 输出 `SGVsbG8sIEZvcm1hdEZvcmdlIQ==`

**解码**：输入 `SGVsbG8sIEZvcm1hdEZvcmdlIQ==` → 输出 `Hello, FormatForge!`

### 3. AES-GCM 加密/解密

使用 AES-256-GCM 算法对文本进行加密和解密，所有操作均在浏览器本地完成。

#### 操作步骤

**加密**：

1. 选择「加密 (Encrypt)」模式
2. 在密码框中输入加密密码
3. 在输入区域输入要加密的明文
4. 加密结果（Base64 格式密文）实时显示

**解密**：

1. 选择「解密 (Decrypt)」模式
2. 在密码框中输入解密密码（必须与加密时相同）
3. 在输入区域粘贴 Base64 格式的密文
4. 解密结果实时显示

#### 配置选项

| 选项 | 说明 |
|------|------|
| 密码 | 加密/解密使用的密码，支持显示/隐藏切换 |
| 密码强度指示器 | 加密模式下显示密码强度（Very Weak / Weak / Fair / Strong / Very Strong） |

> **重要提示**：请妥善保管密码。如果忘记密码，将无法恢复加密内容。密码不会被发送到任何服务器。

### 4. 颜色格式转换器

在 HEX、RGB、HSL、RGBA、HSLA 等颜色格式之间自由转换。

#### 操作步骤

1. 在输入框中输入颜色值，支持以下格式：
   - HEX：`#3B82F6` 或 `3B82F6`
   - RGB：`rgb(59, 130, 246)`
   - HSL：`hsl(217, 91%, 60%)`
   - RGBA：`rgba(59, 130, 246, 1)`
   - HSLA：`hsla(217, 91%, 60%, 1)`
2. 也可以点击右侧的颜色选择器（色块）从调色板中选取颜色
3. 所有等效格式会自动列出，每种格式旁都有「复制」按钮

#### 配置选项

| 选项 | 说明 |
|------|------|
| 颜色输入框 | 手动输入颜色值 |
| 颜色选择器 | 点击色块打开系统调色板 |
| 常用颜色 | 快速选取 12 种预设颜色（Red、Orange、Amber 等） |
| 颜色预览 | 实时显示当前颜色的大色块预览 |

#### 示例

输入 `#3B82F6`，将显示：

| 格式 | 值 |
|------|-----|
| HEX | #3B82F6 |
| RGB | rgb(59, 130, 246) |
| HSL | hsl(217, 91%, 60%) |
| RGBA | rgba(59, 130, 246, 1) |
| HSLA | hsla(217, 91%, 60%, 1) |

### 5. JSON 格式化/压缩/校验

对 JSON 数据进行美化格式化、压缩或语法校验。

#### 操作步骤

1. 选择操作模式：「格式化」、「压缩」或「校验」
2. 在输入区域粘贴 JSON 数据
3. 点击操作按钮执行转换

> 注意：此工具需要手动点击按钮执行，非实时转换。

#### 配置选项

| 选项 | 说明 | 默认值 |
|------|------|--------|
| 缩进方式 | 格式化模式下的缩进选项：2 空格、4 空格、Tab | 2 空格 |

#### 校验模式说明

校验模式会检查 JSON 语法是否正确：

- **通过**：显示绿色「JSON 格式正确 ✓」

#### 示例

**压缩输入**：

```json
{
  "name": "FormatForge",
```

```json
{"name":"FormatForge","version":1}
```

### 7. URL 编解码

URL 编码解码以及查询参数的解析与构建。

#### 操作步骤

选择以下四种模式之一：

**URL 编码**：

1. 选择「URL 编码」模式
2. 输入需要编码的文本或 URL
3. 点击「编码」按钮，输出编码后的字符串

**URL 解码**：

1. 选择「URL 解码」模式
2. 输入 URL 编码字符串（如 `%E5%BC%A0%E4%B8%89`）
3. 点击「解码」按钮，输出解码后的文本

**参数解析**：

1. 选择「参数解析」模式
2. 输入完整 URL 或查询字符串（如 `https://example.com?name=张三&age=25`）
3. 点击「解析参数」按钮，以表格形式展示所有参数的键值对
4. 每个参数值旁有复制按钮

**参数构建**：

1. 选择「参数构建」模式
2. 在键值对输入框中填写参数名和参数值
3. 点击「+ 添加参数」增加更多键值对，点击垃圾桶图标删除
4. 点击「构建查询字符串」生成结果

#### 示例

**参数解析输入**：`https://example.com?name=张三&age=25`

**解析结果**：

| 参数名 | 参数值 |
|--------|--------|
| name | 张三 |
| age | 25 |

### 8. 时间戳转换

Unix 时间戳与人类可读日期之间的互相转换。

#### 操作步骤

**时间戳 → 日期**：

1. 选择「时间戳 → 日期」方向
2. 输入 Unix 时间戳（秒级如 `1700000000` 或毫秒级如 `1700000000000`）
3. 点击「转换为日期」按钮
4. 查看结果：ISO 8601 格式、本地时间、相对时间

**日期 → 时间戳**：

1. 选择「日期 → 时间戳」方向
2. 在日期选择器中选择或输入日期时间
3. 点击「转换为时间戳」按钮
4. 查看结果：秒级时间戳和毫秒级时间戳

#### 特殊功能

- **当前时间戳**：页面顶部实时显示当前 Unix 时间戳（秒/毫秒）和本地时间，可一键复制
- **自动检测**：输入时间戳时自动判断是秒级还是毫秒级
- **相对时间**：显示如「2 小时前」「3 天后」等相对时间描述
- **常见格式参考**：页面底部提供 ISO 8601、RFC 2822、Unix 秒/毫秒的格式示例

### 12. JWT 解析器

解析和查看 JWT（JSON Web Token）的 Header、Payload 和 Signature 内容。

#### 操作步骤

1. 在输入区域粘贴 JWT Token（格式为 `xxxxx.yyyyy.zzzzz`）
2. 解析结果实时显示，包含以下内容：
   - **过期状态**：显示 Token 是否已过期（绿色「有效」或红色「已过期」）
   - **Header**：Token 头部信息（算法、类型等）
   - **Payload**：Token 载荷信息（用户数据、过期时间等）
   - **Signature**：Token 签名部分

#### 特殊功能

- **语法高亮**：Header 和 Payload 的 JSON 内容带有语法高亮（键名蓝色、字符串绿色、数字橙色、布尔值橙色、null 紫色）
- **过期检测**：自动检查 `exp` 字段，显示精确的过期时间描述（如「2 小时后过期」「3 天前过期」）
- **一键复制**：Header 和 Payload 各有独立的复制按钮

> **注意**：此工具仅解析 JWT 内容，不验证签名的真实性。

## 常见问题解答

### 一般问题

**Q：我的数据安全吗？**

A：完全安全。所有数据处理都在你的浏览器本地完成，没有任何数据会被上传到服务器。关闭页面后，所有输入和输出数据都会消失。

**Q：支持离线使用吗？**

A：FormatForge 支持 PWA，首次访问后可以离线使用基本功能。

**Q：转换结果可以保存吗？**

A：可以。每个工具的输出区域都有「下载」按钮，可以将结果保存为文件。也可以使用「复制」按钮将结果复制到剪贴板。

**Q：支持哪些浏览器？**

A：推荐使用最新版 Chrome、Firefox、Safari 或 Edge 浏览器。

### JSON ↔ CSV

**Q：CSV 中的字段包含逗号怎么办？**

A：包含逗号、换行符或双引号的字段会自动用双引号包裹，符合标准 CSV 规范。

**Q：支持嵌套的 JSON 对象吗？**

A：支持。开启「展开嵌套对象」选项后，嵌套对象会被展开为扁平的列名（如 `address.city`）。关闭此选项则嵌套对象会以 JSON 字符串形式输出。

### Base64

**Q：编码后的文件如何还原？**

A：切换到「解码」模式，粘贴编码结果（包括 Data URL 前缀），如果检测到 Data URL，会自动提供「下载解码文件」按钮。

### 加密/解密

**Q：忘记密码怎么办？**

A：很遗憾，AES-GCM 加密无法在没有密码的情况下解密。请务必妥善保管你的密码。

**Q：加密算法安全吗？**

A：使用的是 AES-256-GCM，这是目前广泛使用的强加密算法。安全性取决于密码的复杂度，建议使用强密码（密码强度指示器显示 Strong 或 Very Strong）。

### 颜色转换

**Q：支持 CSS 颜色名称吗？**

A：目前不支持 CSS 颜色名称（如 `red`、`blue`），请使用 HEX、RGB 或 HSL 格式输入。

### 时间戳

**Q：如何区分秒级和毫秒级时间戳？**

A：工具会自动检测：如果时间戳数值小于 10^12，判定为秒级；否则判定为毫秒级。输入时也会显示检测提示。

### JWT

**Q：能验证 JWT 签名吗？**

A：不能。此工具仅解析 JWT 的内容（Header 和 Payload），不验证签名的真实性。任何 JWT 都可以被解析，无论签名是否有效。

**Q：为什么显示「已过期」？**

A：JWT 的 `exp`（expiration）字段表示过期时间。如果当前时间已超过该时间，工具会显示「已过期」标记。
